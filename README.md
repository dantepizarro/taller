Este proyecto consiste en un menu en java que permite gestionar el tiempo que realizan ciertas actividades algunos usuarios. Este menu permite: Registrar, modificar
y/o eliminar las actividades de los usuarios, cambiar sus contraseñas y usar el menu de analisis para: mostrar la actividad mas realizada en general y por usuario,
el usuario con mas horas de procastinacion y visualizar todos los registros

Dante Pizarro 22.216.463-k GitHub: dantepizarro

El archivo se estructura como en la ide Eclipse, con una carpeta src que contiene el paquete taller en el cual se encuentra la clase Taller1 con el programa.
A su par se encuentra la carpeta txt que contiene los dos archivos.txt

Para ejecutar este programa requerira una ide con java instalado, al ejecutarlo, debera colocar el numero de la opcion que desea en la linea de "seleccione: "
